# 🤖 AI Text Generator

An AI-powered text generation application built using **Python, Streamlit, Hugging Face Transformers, and GPT-Neo 125M**.

This application allows users to enter a text prompt and generate AI-powered text based on the given input through a simple and interactive web interface.

## ✨ Features

* 🤖 AI-powered text generation
* 💬 Generate text from user-provided prompts
* 🖥️ Simple and user-friendly Streamlit interface
* 🤗 Uses Hugging Face Transformers
* ⚡ Interactive web application
* 🧠 Powered by GPT-Neo 125M
* 🐍 Built using Python
* 📚 Useful for learning and experimenting with Generative AI
* 💻 Easy to install and run locally

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Hugging Face Transformers**
* **PyTorch**
* **GPT-Neo 125M**

## 🔄 How It Works

```text
User enters a prompt
        ↓
Streamlit Interface
        ↓
GPT-Neo 125M Model
        ↓
AI processes the prompt
        ↓
Generated text is displayed
```
